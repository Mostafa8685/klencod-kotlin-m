# Chrono Knight: Era of Monsters (فارس الزمن: صراع العصور)
🎮 **لعبة أندرويد 2D قتالية قائمة على القصة بلغة Kotlin ومصممة بتقنية Pixel Art.**

---

## 📖 قصة اللعبة (The Story)
تتحطم "جوهرة الكرونو" (Chrono Keystone) السحرية ويتصدع نسيج الزمن، مما يؤدي إلى تسرب وحوش وظلام عبر أزمنة مختلفة. ينطلق البطل **"أرجوس - فارس الزمن"** في رحلة ملحمية لقتال قادة الظلام واستعادة شظايا الحجر عبر ثلاثة عصور:

1. **العصر الأول: قلعة القرون الوسطى (Medieval Fortress):**
   - مواجهة الفرسان الملعونين وهزيمة الزعيم "الفارس الأسود" لفتح بوابة الكهوف السفلية.
2. **العصر الثاني: سراديب وكهوف الموت (Ancient Caverns & Dungeons):**
   - تفادي الأفخاخ الحارقة وهزيمة وحوش الظلام وزعيم الكهوف الحجري لاستعادة الشظية الثانية.
3. **العصر الثالث: العصر الحديث ونهاية العالم (Ruined Zombie City):**
   - قتال جحافل الزومبي والوحش الطافر الأكبر (Apocalypse Titan) لختم اللعبة نهائياً واستقرار خط الزمن!

---

## 🕹️ أسلوب اللعب والتحكم (Controls & Mechanics)
- **عصا التحكم الافتراضية (Virtual Joystick):** في الجانب الأيسر السفلي للتحكم بالحركة بسلاسة في جميع الاتجاهات (Multi-touch).
- **زر الهجوم (Attack Button):** لتنفيذ ضربات السيف والسحر ضد الأعداء.
- **زر التفاعل (Interact / Advance):** لعبور بوابات الزمن والتنقل بين العصور عند هزيمة الزعماء.
- **شريط الصحة ونظام الحوار:** متابعة نقاط حياة البطل وقراءة حوارات القصة المترجمة للعربية والإنجليزية.

## 🚀 كيفية تحويل المشروع إلى تطبيق أندرويد (APK) باستخدام GitHub مجاناً وبدون تثبيت برامج:

المشروع مجهز بالكامل بملف **GitHub Actions Workflow** يقوم ببناء الـ APK تلقائياً بمجرد رفع الملفات!

### الخطوات خطوة بخطوة:
1. **إنشاء مستودع على GitHub:**
   - افتح موقع [GitHub.com](https://github.com) وسجل الدخول.
   - اضغط على زر **New Repository** وسمّه مثلاً `chrono-knight-game`.
   - اجعله **Public** ثم اضغط **Create Repository**.

2. **رفع ملفات المشروع:**
   - فك ضغط ملف الـ ZIP الذي قمت بتحميله على جهازك.
   - ارفع جميع الملفات والمجلدات الموجودة داخل المجلد (بما فيها مجلد `.github` و `app` و `gradle` وجميع الملفات) إلى المستودع عن طريق خيار **Upload files** أو باستخدام Git:
     ```bash
     git init
     git add .
     git commit -m "Initial Chrono Knight Game"
     git branch -M main
     git remote add origin https://github.com/USERNAME/chrono-knight-game.git
     git push -u origin main
     ```

3. **البناء التلقائي للـ APK (GitHub Actions):**
   - بمجرد رفع الملفات، اذهب إلى تبويب **Actions** في أعلى صفحة المستودع على GitHub.
   - ستلاحظ أن هناك عملية بناء بعنوان **"Build Android APK"** بدأت تلقائياً وتعمل في الخلفية.
   - انتظر حوالي دقيقتين حتى تظهر علامة الصح الخضراء (Green Checkmark ✅).

4. **تحميل وتثبيت الـ APK على هاتفك:**
   - اضغط على الـ Run المكتمل في صفحة Actions.
   - انزل لأسفل الصفحة عند قسم **Artifacts**.
   - اضغط على **`ChronoKnight-Game-APK`** لتحميل ملف الـ APK مباشرة.
   - انقله لهاتفك الأندرويد، وثبته واستمتع باللعبة!

## 💻 الفتح والتعديل في Android Studio (اختياري للمطورين)
إذا أردت التعديل على اللعبة أو إضافة مراحل جديدة بنفسك:
1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد مجلد المشروع `chrono_knight_game`.
3. سيتعرف البرنامج تلقائياً على Gradle وملفات Kotlin.
4. اضغط على زر **Run ▶** لتشغيل اللعبة مباشرة على المحاكي (Emulator) أو هاتفك المتصل.
