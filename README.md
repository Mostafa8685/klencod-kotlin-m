# Mango IDE (com.apk3rade.mangoide)

تطبيق بيئة تطوير متكاملة (IDE) أصلي ومفتوح المصدر بلغة Kotlin مصمم لموقع وقناة **Apk3rade** (`@apk3rade`).

## المميزات الأساسية
- **بدون تطبيق بناء خارجي:** يعتمد على البناء السحابي المباشر عبر **GitHub Actions** (مع ملف `.github/workflows/android-build.yml` جاهز).
- **محرر أكواد مدمج يعمل بدون إنترنت:** تلوين للغات Kotlin وJava وXML وHTML وCSS وJS وDart، مع أرقام الأسطر وشريط رموز برمجية وحفظ تلقائي ومعاينة فورية لملفات HTML.
- **قوالب مشاريع جاهزة:** أندرويد Kotlin، ويب عربي RTL، Flutter/Dart، ومشروع فارغ.
- **مساعد ذكاء اصطناعي (AI):** يدعم أي مزود متوافق مع OpenAI مع إرفاق الكود المفتوح.
- **تكامل قناة التليجرام:** أزرار مدمجة للوصول المباشر إلى قناة `@apk3rade`.

## خطوات البناء (GitHub Actions)
1. ارفع محتويات المشروع إلى مستودع على GitHub.
2. افتح تبويب **Actions** وشغّل Workflow باسم **Build Mango IDE APK**.
3. حمّل ملف **MangoIDE-debug-apk** الجاهز للتثبيت من قسم Artifacts.
